Support

Markdown Manager for Google Docs™

Need help with the add-on, or want to report a problem? You can reach the developer directly using the channels below.

Troubleshooting

If the sidebar or preview dialog fails to load with a "Page not found" or 404 error, it is most likely caused by being signed into multiple Google accounts in the same browser — a known limitation of Google Apps Script. The linked page lists the available workarounds (incognito window, separate Chrome profile, or signing out of other accounts).

Contact the developer

For questions, bug reports, feature requests, or anything else, email info@riccardobianconi.it.

We aim to respond within 10 business days.

Report a bug or request a feature

Public bug reports and feature requests can be filed on the GitHub issue tracker. A free GitHub account is required to open an issue there; if you prefer not to use GitHub, email the developer at the address above instead.

Self-service documentation

Before reaching out, you may find an answer in the help page:

  • Help & Documentation — installation, sidebar overview, supported Markdown syntax, drag-and-drop reordering, theme toggle.
  • Privacy Policy — what data the add-on accesses and how it is handled.
  • Terms of Service — terms governing use of the add-on.

What to include when contacting support

To help us reproduce and fix issues quickly, please include the following whenever possible:

  • A short description of the problem and what you expected to happen.
  • Steps to reproduce.
  • Add-on version (shown in the Credits dialog inside the sidebar).
  • Browser and operating system.
  • A screenshot or short screen recording, if applicable.
  • Whether the Google Doc is owned by you or shared with you, and whether you have edit permission.

Please do not share document content that you consider confidential — a redacted snippet or a minimal example document that reproduces the issue is sufficient.

Uninstalling or revoking access

You can uninstall the add-on at any time from Google Workspace Marketplace, and revoke its access to your Google account at myaccount.google.com/permissions.
