## Apps in the suite

### [Markdown Manager for Google Docs™](https://github.riccardobianconi.it/markdown-suite-for-google-workspace/docs-manager/)

`Google Docs Add-on` · `Free`

Interactive sidebar for Google Docs that reads Markdown syntax written directly in your document — navigate headings, search, reorder sections, and preview rendered Markdown without leaving Docs.

<a href="https://workspace.google.com/marketplace/app/markdown_manager_for_google_docs/269946648665"><img src="https://workspace.google.com/static/img/marketplace/en/gwmBadge.svg" alt="Available on Google Workspace Marketplace" width="280"></a>

### [Markdown Viewer for Google Drive™](https://github.riccardobianconi.it/markdown-suite-for-google-workspace/drive-viewer/)

`Google Drive Web App` · `Free`

Open one or more `.md` files stored in Google Drive and see them rendered as formatted HTML — works as a native "Open with" handler in the Drive file list.

<a href="https://workspace.google.com/marketplace/app/markdown_viewer_for_google_drive/995625902344"><img src="https://workspace.google.com/static/img/marketplace/en/gwmBadge.svg" alt="Available on Google Workspace Marketplace" width="280"></a>
